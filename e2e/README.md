# e2e — browser checks

Playwright scripts that drive the real game in Chromium. Start the web app (`pnpm dev`, :3100) — or, for `online.mjs`, the Worker (`pnpm worker:dev`, :8787: site + online rooms) — then:

```bash
cd e2e && npm i && npx playwright install chromium
node controls.mjs      # keyboard legend vs touch pads per device, gamepad
node mobile.mjs        # iPhone / Pixel / iPad layouts (DEVICES="iPhone 13,Pixel 7" to pick)
node card.mjs          # Fighter Card explains the stats
node powers.mjs        # every drawn power + counters
node twop.mjs          # two players on one keyboard
node feel.mjs          # hit-stop, KO slow-mo, replay, Save clip
node sfx.mjs           # every sound credited, served, decoded and fired on the right frame
node online.mjs        # two browsers, one room, lockstep in sync (also over lag)
node human.mjs         # a "casual human" bot plays real rounds
```

Screenshots go to `e2e/shots/` (git-ignored). `BASE=` overrides the URL, `CHROME=` points at a specific Chromium binary. Every launch maps `fonts.googleapis.com` / `fonts.gstatic.com` to NOTFOUND so tests never hang on the web-font request on offline or restricted networks (the system fallback font is used).
`drawings.json` (the shared test drawings) is regenerated by `pnpm --filter @nf/sim test:recognize`.
